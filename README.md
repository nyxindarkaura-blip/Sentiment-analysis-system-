# Sentiment Analysis System

A simple rule-based sentiment analysis system built with Python. The program analyzes a user's sentence by looking for predefined positive and negative words, handling basic negation, and determining whether the overall sentiment is positive, negative, or neutral.

## Features

- ✅ Accepts user input via command line
- ✅ Converts text to lowercase and removes punctuation
- ✅ Splits sentences into individual words
- ✅ Counts positive and negative words
- ✅ Displays matched words for transparency
- ✅ Handles simple negation (e.g., "don't love")
- ✅ Returns Positive, Negative, or Neutral sentiment
- ✅ Modular architecture with separate Python modules
